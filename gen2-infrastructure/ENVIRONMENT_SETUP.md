# Gen 2 Environment Setup Checklist

## Required Before Migration

### 1. AWS Account Configuration

**SES Email Verification (us-west-2 only):**
```bash
# Verify sending email address
aws ses verify-email-identity \
  --email-address noreply@smalgyax-files.org \
  --region us-west-2

# Check verification status
aws ses get-identity-verification-attributes \
  --identities noreply@smalgyax-files.org \
  --region us-west-2
```

**Alert Email Verification:**
```bash
# Verify alert recipient email
aws ses verify-email-identity \
  --email-address Tom.Burton@Outlook.com \
  --region us-west-2
```

**SES Production Access (if not already enabled):**
- Request production access in SES console (us-west-2)
- Current status: Already in production mode

### 9. Pre-Migration Verification

**Run these commands to verify current state:**

```bash
# Check AWS credentials
aws sts get-caller-identity

# Check SES status (us-west-2)
aws ses get-account-sending-enabled --region us-west-2

# Check verified email identities
aws ses list-identities --region us-west-2

# Check current OpenSearch domains
aws opensearch list-domain-names --region us-west-2

# Check current DynamoDB tables
aws dynamodb list-tables --region us-west-2

# Check current S3 buckets
aws s3 ls | grep amplify
```

### 10. Post-Migration Manual Steps

**BLOCKING: API-Level Validation (REQUIRED BEFORE PRODUCTION)**
- [ ] Implement API-level validation for required relationships
- [ ] See `gen2-infrastructure/API_VALIDATION_REQUIRED.md` for details
- [ ] All resolver files ready in `amplify/data/resolvers/`
- [ ] Choose implementation approach (Lambda resolvers recommended)
- [ ] Test validation with direct API calls

**After running `npm run setup:dev` or `setup:prod`:**

1. **Create Admin User:**
   - Open web app
   - Sign up with your email
   - Note your user ID

2. **Add to WebAppAdmin Group:**
   ```bash
   aws cognito-idp admin-add-user-to-group \
     --user-pool-id <pool-id> \
     --username <your-email> \
     --group-name WebAppAdmin \
     --region <region>
   ```

3. **Update OAuth Redirect URLs:**
   - Google: Add new Cognito domain to authorized redirects
   - Facebook: Add new Cognito domain to valid OAuth redirects
   - Amazon: Add new Cognito domain to allowed return URLs

4. **Test Email Sending:**
   - Upload a document
   - Verify email notification received
   - Check unsubscribe link works

5. **Verify Search:**
   - Upload document with text content
   - Wait 30 seconds for indexing
   - Search for content
   - Verify results appear
