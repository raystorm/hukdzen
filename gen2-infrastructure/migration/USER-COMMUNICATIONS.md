## FAQ for Support

**Q: Why do I need to reset my password?**
A: We upgraded to a new authentication system for improved security.
   Google/Facebook/Amazon logins are unaffected,
   but email/password users need to create a new password.

**Q: Are my documents safe?**
A: Yes! All documents, collections, and boxes have been migrated and are safe.

**Q: What happened to my pending box access request?**
A: Pending requests were not migrated as they are temporary/operational.
   Please resubmit your request after logging in.

**Q: My box memberships are gone!**
A: Box memberships were migrated. Try logging out and back in. If still missing, contact support.

**Q: I can't login with Google/Facebook/Amazon**
A: OAuth logins should work immediately. Clear your browser cache and try again.
   Contact support if issues persist.

**Q: How long will password reset emails take?**
A: Password reset emails should arrive within a few minutes. Check your spam folder if you don't see it.

**Q: I reset my password but still can’t log in.**  
A: Make sure you’re using the same email address you originally used to create your account.
   If the issue continues, contact support.
