Contributing to Smalgyax‑Files
==============================

Thank you for your interest in contributing!  
This project uses a domain‑driven structure and a few shared patterns
to keep the codebase maintainable, but none of this is meant to be overwhelming or rigid.

These documents are **references**, not rules.  
They describe how the project is organized and how we *usually* work — not how you must work.  
People make mistakes. Patterns evolve. Working code always wins over perfect process.

If you write clear code, keep changes focused,
and try to follow the spirit of the project, you’re contributing the right way.  
The rest of this guide simply gives you tools to make that easier.

---

Quickstart
----------

If you want to jump in quickly:

1. Clone the repo
2. Install dependencies (`npm install`)
3. Start the dev server (`npm start`)
4. Run the tests (`npm test`)
5. Make a focused change
6. Write a clean, easy‑to‑follow commit (optionally using the Commit Style Guide)
7. Open a PR that follows the expectations below

Everything else in this guide is optional reference material you can explore as needed.
